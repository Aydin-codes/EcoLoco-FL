# Security

Please don't report security problems in a public issue.

Use **[Report a vulnerability](https://github.com/Aydin-codes/EcoLoco-FL/security/advisories/new)** on this repo's Security tab instead. Only the maintainers can see it.

Things we especially want to hear about:

- A way to read our API keys, or to make the backend spend them for you
- A way to get a user's location, photos or saved audits
- Anything that lets someone change what the app says about a plant
